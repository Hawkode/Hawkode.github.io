About Me

I'm an IT Service Engineer running a hybrid Microsoft environment across two UK sites: Active Directory, Microsoft Entra ID through Entra Connect, Microsoft 365, and about 120 Windows endpoints. My day-to-day covers the identity lifecycle, patching, vulnerability remediation and the technical controls behind our Cyber Essentials certification.

The area that interests me most is identity and access management: how the identity lifecycle should run, how to design access around least privilege, who should keep what, and how identity gets attacked and detected. My projects follow that pattern: build it, break it in a lab, detect it, harden it.

It started with a PC I built as a kid and a lot of time spent working out how it fit together. I still like seeing how the whole stack connects, from a patch panel to a Conditional Access policy, and I learn best by building something, breaking it and writing down what I found. The same curiosity now goes into following a sign-in log or an event ID until it explains what happened.

IAM Lab in Microsoft Entra ID

Built a full identity environment from an empty Entra ID tenant: attribute-driven dynamic groups, the joiner-mover-leaver lifecycle tested end to end, MFA and Conditional Access enforced after a report-only phase, legacy authentication blocked, and a break-glass account proven in the sign-in logs. Added PIM, access reviews, entitlement management, SAML SSO and a least-privilege workload identity.

The lifecycle and reporting work is automated in entra-iam-automation: PowerShell and Microsoft Graph for cloud and hybrid joiners, movers and leavers, access review campaigns, and reports on standing admins, stale accounts and risky app consents.

Hybrid Identity: Two-Site Domain Consolidation

Merged two site domains into a single Active Directory domain, with a Windows Server 2022 domain controller (AD DS, DNS, DHCP) in each office, then redesigned the OU structure and verified replication. Migrated 60+ user accounts with ADManager Plus and matched each to its existing Microsoft Entra ID identity, so staff moved to one synced identity and password for Windows sign-in and Microsoft 365.

Replaced manual domain joins with a PowerShell script deployed through ManageEngine, moved file shares with Robocopy while keeping NTFS permissions, and ran each user's cutover.

Active Directory • Microsoft Entra ID • Entra Connect • Windows Server 2022 • OU Design • ADManager Plus • PowerShell

Windows Endpoint Security: Attack, Detect, Harden

A three-part series on one Windows host. Escalate from a low-privilege foothold to SYSTEM, catch each technique in Splunk with alerts mapped to MITRE ATT&CK, then harden the host with a tested PowerShell module that checks Defender, firewall, patching, BitLocker and log clearing, and reports to the same SIEM.
