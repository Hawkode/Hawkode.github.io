Windows Endpoint Security: Attack, Detect, Harden

A three-part series on one Windows host, taken from both sides: how an attacker escalates, how Splunk catches it, and a tool that keeps the endpoint's defences honest and reports to the same SIEM.

  • 1. Attack: Windows Privilege Escalation. Common local escalation vectors, the event IDs and Sysmon signals for each, and the configuration that closes them.
  • 2. Detect: Detecting Privilege Escalation in Splunk. The same techniques as SPL searches and scheduled alerts, mapped to MITRE ATT&CK.
  • 3. Harden: Windows Health Monitor. A tested PowerShell module that checks Defender, firewall, patching, BitLocker and log clearing, writes findings and a heartbeat to the event log, and refuses to run as SYSTEM from a folder users can change. (GitHub)
